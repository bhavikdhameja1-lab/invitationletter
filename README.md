# Bhavik ki Diwali Baithak

A mobile-friendly invitation prototype for Bhavik's birthday and Diwali celebration. The 2D illustrated sequence opens a matchbox, strikes and carries a match to the invitation cover, then reveals the event card. It includes reduced-motion support and is built with plain HTML, CSS, and JavaScript; no plugin or build step is required. The supplied Canva PDF exports are included as downloadable designs.

## Preview locally

Open `index.html` in a browser. The page uses plain HTML, CSS, and JavaScript and has no build or install step.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.
5. After GitHub Pages finishes deploying, use the URL shown in the Pages settings to share the invitation.

The invitation PDFs are in `assets/cover.pdf` and `assets/invitation.pdf`.
